# DFlex

**DFlex** is an AI-powered personalized diet planner designed with a hardcore, high-energy aesthetic for serious athletes and fitness enthusiasts. It dynamically generates custom meal plans based on macros, budget, and body goals.

## Features
- **AI Diet Generation**: Get personalized meal plans instantly.
- **Dynamic Swaps**: Use the AI Coach to swap out meals without breaking your macros.
- **Progress Tracking**: Visualize your calorie intake and body weight changes using Recharts.
- **Aggressive Gym Aesthetic**: High-contrast dark mode with neon accents designed for peak performance.

## Tech Stack
- **Frontend Framework**: React 18 & Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Data Visualization**: Recharts

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
